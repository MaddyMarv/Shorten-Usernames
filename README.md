### [Shorten Usernames](https://www.nexusmods.com/warhammer40kdarktide/mods/641)
<img width="1304" height="497" alt="image" src="https://github.com/user-attachments/assets/23f0c884-8baa-4d08-a853-36b36bcee5b7" />

Shortens long player and character names on your HUD with customizable character limits and truncation styles.

**Options:**

**General**
- Shorten Myself
- Shorten Teammates
- Only Shorten in Gameplay
- Truncation String [..., .., ., -, ~, None]

**Lengths**
- Enable Shorten Character Name
- Max Character Name Length
- Enable Shorten Account Name
- Max Account Name Length
